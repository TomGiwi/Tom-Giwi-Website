# Tom Giwi Portfolio — First Version

## Open the site
Double-click `index.html` to open the website in a browser.

## Replace the placeholder artwork
The coloured abstract placeholders are there only to establish the layout.

Later, we can replace them with your actual images. The simplest next version can use:
`<img src="../assets/your-image.jpg" alt="">`

## Edit project names
Open `index.html` in any text editor and change the project titles/dates.

## Important things to replace
- Instagram URL: currently `https://instagram.com/`
- Email: currently `hello@example.com`
- Information page text
- Placeholder artwork

This version intentionally has no framework, no CMS and no dependency on Cargo.
